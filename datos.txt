def preprocess_data(df):
    df['date'] = pd.to_datetime(df['timestamp'])
    df = df.sort_values('date')
    df = df.dropna()
    return df

---------ML Pipeline / Patrón Strategy

Archivo: model.py o dentro del main.

from sklearn.linear_model import LinearRegression

def predict_prices(df):
    model = LinearRegression()
    X = df[['timestamp']]
    y = df['price']
    model.fit(X, y)
    df['predicted'] = model.predict(X)
    return df


El modelo de predicción es intercambiable. Si mañana cambias LinearRegression por RandomForest, no tocas la vista ni la estructura general.
